## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Yogeth/my-portfolio.git
   cd my-portfolio
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Featured Projects

### 1. **Weather App**
A modern weather dashboard built with React that fetches real-time weather data from external APIs. Demonstrates live city search, multi-day forecasts, humidity tracking, and fully responsive design that adapts seamlessly across mobile, tablet, and desktop devices.

**Tech Stack:** React 18, CSS3, REST APIs, Responsive Design

### 2. **ComplainTrack**
Enterprise-level complaint management system designed to streamline issue tracking within IT departments. Features a React frontend for intuitive complaint submission with role-based dashboards, and a Spring Boot backend with MariaDB persistence. Handles hardware failures, software issues, billing concerns, and network problems through a centralized platform.

**Tech Stack:** React, Spring Boot 3, REST APIs, MariaDB, Docker

### 3. **Task Manager**
A productive task management application built with React that enables users to create, update, complete, and organize tasks through an intuitive interface. Focuses on improving workflow efficiency with real-time task updates, smart filtering options, and clean UI patterns using modern React hooks and state management.

**Tech Stack:** React Hooks, State Management, CSS3

### 4. **Hot Servlet**
Intelligent deployment automation tool that revolutionizes Java Servlet development workflows. Automatically handles WAR file building with Gradle, Apache Tomcat installation and configuration, application deployment, and server launch through a single command. Significantly reduces deployment time and eliminates manual configuration errors.

**Tech Stack:** Bash, Gradle, Apache Tomcat, Automation
